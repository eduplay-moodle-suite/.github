# Boas-vindas à **EduPlay Moodle Suite**!

A **EduPlay Moodle Suite** é uma suíte completa para integração e suporte ao **EduPlay** (RNP) no **Moodle** (não oficial).

Nosso ecossistema reúne módulos de atividades, filtros de mídia, extensões para editores de texto e utilitários voltados para facilitar a incorporação, reprodução e administração de conteúdos audiovisuais do portal EduPlay nas salas virtuais do Moodle.

Confira mais detalhes no portal oficial da organização:

> 🌐 [https://eduplay-moodle-suite.github.io](https://eduplay-moodle-suite.github.io)
